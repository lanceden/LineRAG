璿恩智慧客服系統部署規劃案

一、專案背景

針對企業導入 AI 智能客服系統需求，專注於單租戶深度優化架構，提供穩定的地端推理能力與資料隱私保護，支援 LINE 訊息串接、官網自訂對話框、RAG 檢索、對話記錄管理等核心功能。本系統採用單機優化設計，確保每個客戶擁有獨立且高效能的AI客服環境。

二、主機架構建議

1. 地端主機（自建）

項目 規格建議 說明
GPU RTX 5090 x1（可擴充雙卡） 單卡支援 20-30 併發用戶，支援 Qwen2-7B、Yi-9B 等中型模型；如需更高併發可升級雙卡
* 建議可支援模型（多模態佳，中文優先，考量 RTX 5090 兼容性）：
* gpt-oss (20B)
* Qwen2.5-VL-instruct (32B)
* MiniCPM (7B)
CPU Intel Xeon / AMD Threadripper 多線程文件處理與檢索分流
RAM 128GB DDR5 ECC 確保文件快取與模型 Loading 穩定
儲存 系統：2TB NVMe SSD向量：4TB SSD RAID 應對 RAG 檢索、大量日誌與文件儲存
作業系統 Windows Server 2022（或 Ubuntu 22.04 LTS，視維運能力調整） Windows Server 對 CUDA 支援佳，並無 TCP 連線限制，適合正式對外服務使用。可搭配 LM Studio / Ollama 建置本地模型推理環境，亦可作為混合式架構的主伺服器平台。若需進一步彈性與 DevOps 自動化，仍建議日後轉移至 Ubuntu，整合容器部署與開源工具鏈（如 FastAPI、NVIDIA Container Toolkit 等）
散熱 水冷 / 工業塔型風冷 適應高熱 GPU 長時運行
網路 1Gbps 固定 IP 對接外部 LINE webhook 與客服管理平台

📌 特色

  • 模型與 RAG 可完全私有部署，資料不出外部。
  • 預留多卡插槽，可日後升級至 2x5090、或部署獨立 embedding node。
  • 成本控制，無需長期 API Token 支出。

2. 雲端主機（租用）

項目 規格建議 說明
GPU A100 / H100（依照廠商方案） 通常計費以秒為單位，需精準控流量
雲平台 AWS / GCP / RunPod / Lambda Labs 可搭配容器化推理環境部署模型
計費模式 時數 / Token / 容量流量 計費 價格彈性但成本累積速度快
架構彈性 高，適合多地佈署 可做負載均衡與容錯備援

📌 雲端主機特色

  • 快速佈署，無需維護硬體。
  • 可配合 autoscaling 並行服務多客戶。
  • 適合 PoC 與短期測試階段使用。

🔍 成本分析重點

雲端GPU方案缺點：

  • 持續費用：A100每月約NT$7-11萬，年費NT$84-132萬
  • 高昂成本：H100每月約NT$17-28萬，年費NT$204-336萬
  • 資料安全風險：客戶對話資料需上傳至雲端
  • 網路延遲：海外機房回應時間較慢
  • 依賴性高：無法掌控服務中斷風險

SaaS API方案限制：

  • Token費用不可控：高階模型用量高時每月可達NT$3.5-8萬
  • 資料隱私問題：所有對話都經過第三方
  • 客製化限制：無法調整模型參數
  • 服務依賴風險：API變更影響營運

地端部署優勢：

  • 一次性投資：設備成本約NT$50-200萬，2-3年攤提
  • 快速回本：相比雲端A100方案，約18-28個月回本
  • 完全資料掌控：客戶對話100%私有
  • 無ongoing費用：僅電費與維護成本
  • 效能穩定：不受網路與外部服務影響

三、技術架構決策考量

✅ 地端部署技術優勢

  • 資料隱私保護：完全本地化處理
  • 效能可控：專用硬體資源，回應時間穩定可預測
  • 成本透明：無使用量計費，長期運營成本固定
  • 技術自主：完整技術掌控，可依需求客製化調整

⚠️ 地端部署技術要求

  • 硬體投資：需要專業 GPU 硬體和散熱系統
  • 維運能力：需要 DevOps 和系統管理專業人員
  • 擴容規劃：需要預先規劃硬體擴充方案
  • 備援機制：需要建立適當的備份和災難恢復機制

四、推薦技術架構

單租戶專用部署架構

  1. 核心推理層：地端主機作為主要 AI 推理引擎
  2. 資料處理層：本地向量資料庫和文檔管理
  3. 介面整合層：LINE Bot 和 Web Chat 統一接入
  4. 監控管理層：系統狀態監控和使用分析

系統整合模式

  • 全地端模式：所有組件部署在客戶內網
  • 混合整合：核心 AI 地端，外部服務雲端代理
  • 容器化部署：Docker 容器化便於維護和升級

七、技術要求與環境配置

✅ 系統環境需求

作業系統支援：

  • Windows Server 2022 / Ubuntu 22.04 LTS
  • Docker 支援（可選）
  • Python 3.10+ 執行環境

網路與安全配置：

  • 固定 IP 位址（對接 LINE webhook）
  • SSL 憑證配置
  • 防火牆與埠號管理

效能監控工具：

  • GPU 使用率監控
  • 系統資源管理
  • 推理延遲追蹤

八、部署與維運指南

✅ 推薦部署步驟

  1. 硬體準備：按照建議規格配置主機和GPU
  2. 環境設定：安裝必要的系統套件和依賴項目
  3. 模型部署：配置 vLLM 和向量資料庫
  4. 服務啟動：運行 FastAPI 後端和 Next.js 前端
  5. 測試驗證：進行完整功能測試和效能評估

✅ 維運重點注意事項

  • 定期備份：資料庫和向量檔案定期備份
  • 模型更新：根據業務需求更新AI模型
  • 效能監控：持續監控系統資源使用情況
  • 日誌管理：保存系統運行和對話日誌
  • 安全更新：定期更新系統套件和安全補丁
