## 🐳 Docker 容器化部署 (推薦)

### 步驟 1: 環境準備

#### 安裝 Docker 和 Docker Compose

**Ubuntu/Debian:**
```bash
# 更新套件列表
sudo apt update

# 安裝 Docker
curl -fsSL https://get.docker.com -o get-docker.sh
sudo sh get-docker.sh

# 安裝 Docker Compose
sudo curl -L "https://github.com/docker/compose/releases/latest/download/docker-compose-$(uname -s)-$(uname -m)" -o /usr/local/bin/docker-compose
sudo chmod +x /usr/local/bin/docker-compose

# 將用戶加入 docker 群組
sudo usermod -aG docker $USER
newgrp docker
```

**CentOS/RHEL:**
```bash
# 安裝 Docker
sudo yum install -y yum-utils
sudo yum-config-manager --add-repo https://download.docker.com/linux/centos/docker-ce.repo
sudo yum install -y docker-ce docker-ce-cli containerd.io
sudo systemctl start docker
sudo systemctl enable docker

# 安裝 Docker Compose
sudo curl -L "https://github.com/docker/compose/releases/latest/download/docker-compose-$(uname -s)-$(uname -m)" -o /usr/local/bin/docker-compose
sudo chmod +x /usr/local/bin/docker-compose
```

#### 驗證安裝
```bash
docker --version
docker-compose --version
```

### 步驟 2: 下載專案代碼

```bash
# 克隆專案 (假設您有 Git 存取權限)
git clone https://github.com/your-org/linerag.git
cd linerag

# 或者解壓縮提供的原始碼包
tar -xzf linerag-v2.0.0.tar.gz
cd linerag-v2.0.0
```

### 步驟 3: 環境變數配置

#### 複製環境變數模板
```bash
# API 環境變數
cp apps/api/.env.example apps/api/.env

# Web 環境變數
cp apps/web/.env.example apps/web/.env
```

#### 編輯 API 環境變數 (`apps/api/.env`)
```bash
# 資料庫配置
DATABASE_URL=postgresql://linerag:your_password@postgres:5432/linerag_db

# Qdrant 向量資料庫
QDRANT_URL=http://qdrant:6333
QDRANT_API_KEY=your_qdrant_api_key

# OpenAI API 配置
OPENAI_API_KEY=your_openai_api_key
OPENAI_MODEL=gpt-4

# LINE API 配置 (可選，用於測試)
LINE_CHANNEL_ACCESS_TOKEN=your_line_channel_token
LINE_CHANNEL_SECRET=your_line_channel_secret

# JWT 密鑰
JWT_SECRET_KEY=your_super_secret_jwt_key_here

# 檔案儲存配置
UPLOAD_DIR=/app/uploads
MAX_FILE_SIZE=50MB

# 系統配置
DEBUG=0
LOG_LEVEL=INFO
CORS_ORIGINS=http://localhost:3000,https://your-domain.com
```

#### 編輯 Web 環境變數 (`apps/web/.env`)
```bash
# API 端點
NEXT_PUBLIC_API_URL=http://localhost:8000/api
NEXTAUTH_URL=http://localhost:3000

# NextAuth 配置
NEXTAUTH_SECRET=your_nextauth_secret_key

# 其他配置
NEXT_PUBLIC_APP_NAME=LineRAG 管理後台
```

### 步驟 4: 啟動服務

#### 使用 Docker Compose 啟動
```bash
# 啟動所有服務
docker-compose up -d

# 查看服務狀態
docker-compose ps

# 查看日誌
docker-compose logs -f api
docker-compose logs -f web
```

#### Docker Compose 配置檔案 (`docker-compose.yml`)
```yaml
version: '3.8'

services:
  # PostgreSQL 資料庫
  postgres:
    image: postgres:15
    environment:
      POSTGRES_DB: linerag_db
      POSTGRES_USER: linerag
      POSTGRES_PASSWORD: your_password
    volumes:
      - postgres_data:/var/lib/postgresql/data
      - ./init-scripts:/docker-entrypoint-initdb.d
    ports:
      - "5432:5432"
    restart: unless-stopped

  # Qdrant 向量資料庫
  qdrant:
    image: qdrant/qdrant:v1.7.4
    ports:
      - "6333:6333"
    volumes:
      - qdrant_data:/qdrant/storage
    restart: unless-stopped

  # Redis 快取 (可選)
  redis:
    image: redis:7-alpine
    ports:
      - "6379:6379"
    volumes:
      - redis_data:/data
    restart: unless-stopped

  # LineRAG API 服務
  api:
    build:
      context: ./apps/api
      dockerfile: Dockerfile
    ports:
      - "8000:8000"
    environment:
      - DATABASE_URL=postgresql://linerag:your_password@postgres:5432/linerag_db
      - QDRANT_URL=http://qdrant:6333
      - REDIS_URL=redis://redis:6379
    volumes:
      - ./apps/api:/app
      - api_uploads:/app/uploads
      - rag_storage:/app/rag_storage
    depends_on:
      - postgres
      - qdrant
      - redis
    restart: unless-stopped

  # LineRAG Web 管理介面
  web:
    build:
      context: ./apps/web
      dockerfile: Dockerfile
    ports:
      - "3000:3000"
    environment:
      - NEXT_PUBLIC_API_URL=http://api:8000/api
      - NEXTAUTH_URL=http://localhost:3000
    depends_on:
      - api
    restart: unless-stopped

  # Nginx 反向代理
  nginx:
    image: nginx:alpine
    ports:
      - "80:80"
      - "443:443"
    volumes:
      - ./nginx/nginx.conf:/etc/nginx/nginx.conf
      - ./nginx/ssl:/etc/nginx/ssl
    depends_on:
      - api
      - web
    restart: unless-stopped

volumes:
  postgres_data:
  qdrant_data:
  redis_data:
  api_uploads:
  rag_storage:
```

### 步驟 5: 初始化資料庫

```bash
# 進入 API 容器
docker-compose exec api bash

from app.models.system_user import SystemUser
from app.core.database import SessionLocal
from passlib.context import CryptContext

db = SessionLocal()
pwd_context = CryptContext(schemes=['bcrypt'], deprecated='auto')

admin = SystemUser(
    email='admin@linerag.com',
    password_hash=pwd_context.hash('admin123456'),
    name='系統管理員',
    role='system_admin',
    is_active=True
)

db.add(admin)
db.commit()
print('系統管理員帳號建立成功')
"
```

## 🔧 手動安裝部署

### 步驟 1: 安裝 Python 環境

#### 安裝 Python 3.11+
```bash
# Ubuntu/Debian
sudo apt update
sudo apt install python3.11 python3.11-venv python3.11-dev

# CentOS/RHEL
sudo dnf install python3.11 python3.11-devel
```

#### 建立虛擬環境
```bash
# 建立專案目錄
sudo mkdir -p /opt/linerag
sudo chown $USER:$USER /opt/linerag
cd /opt/linerag

# 建立虛擬環境
python3.11 -m venv venv
source venv/bin/activate

# 升級 pip
pip install --upgrade pip
```

### 步驟 2: 安裝資料庫

#### PostgreSQL 安裝
```bash
# Ubuntu/Debian
sudo apt install postgresql postgresql-contrib

# CentOS/RHEL
sudo dnf install postgresql postgresql-server postgresql-contrib

# 初始化資料庫 (CentOS/RHEL)
sudo postgresql-setup --initdb
```

#### 配置 PostgreSQL
```bash
# 切換到 postgres 用戶
sudo -u postgres psql

-- 建立資料庫和用戶
CREATE DATABASE linerag_db;
CREATE USER linerag WITH PASSWORD 'your_secure_password';
GRANT ALL PRIVILEGES ON DATABASE linerag_db TO linerag;
\q
```

#### Qdrant 安裝
```bash
# 下載並安裝 Qdrant
wget https://github.com/qdrant/qdrant/releases/latest/download/qdrant-x86_64-unknown-linux-gnu.tar.gz
tar -xzf qdrant-x86_64-unknown-linux-gnu.tar.gz
sudo mv qdrant /usr/local/bin/

# 建立 Qdrant 服務
sudo tee /etc/systemd/system/qdrant.service > /dev/null <<EOF
[Unit]
Description=Qdrant Vector Database
After=network.target

[Service]
Type=simple
User=qdrant
WorkingDirectory=/opt/qdrant
ExecStart=/usr/local/bin/qdrant
Restart=always

[Install]
WantedBy=multi-user.target
EOF

# 建立 qdrant 用戶和目錄
sudo useradd -r -s /bin/false qdrant
sudo mkdir -p /opt/qdrant
sudo chown qdrant:qdrant /opt/qdrant

# 啟動服務
sudo systemctl enable qdrant
sudo systemctl start qdrant
```

### 步驟 3: 部署 API 服務

#### 安裝依賴
```bash
cd /opt/linerag
git clone <your-repo-url> .
cd apps/api

# 安裝 Python 依賴
pip install -r requirements.txt
```

#### 配置環境變數
```bash
# 複製環境變數模板
cp .env.example .env

# 編輯環境變數
nano .env
```

#### 建立系統服務
```bash
sudo tee /etc/systemd/system/linerag-api.service > /dev/null <<EOF
[Unit]
Description=LineRAG API Service
After=network.target postgresql.service qdrant.service

[Service]
Type=simple
User=linerag
WorkingDirectory=/opt/linerag/apps/api
Environment=PATH=/opt/linerag/venv/bin
ExecStart=/opt/linerag/venv/bin/uvicorn main:app --host 0.0.0.0 --port 8000
Restart=always

[Install]
WantedBy=multi-user.target
EOF

# 建立 linerag 用戶
sudo useradd -r -s /bin/bash linerag
sudo chown -R linerag:linerag /opt/linerag

# 啟動服務
sudo systemctl enable linerag-api
sudo systemctl start linerag-api
```

### 步驟 4: 部署 Web 介面

curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -

## 🌐 Nginx 反向代理配置

### 安裝 Nginx
```bash
# Ubuntu/Debian
sudo apt install nginx

# CentOS/RHEL
sudo dnf install nginx
```

### 配置檔案 (`/etc/nginx/sites-available/linerag`)
```nginx
server {
    listen 80;
    server_name your-domain.com;

    # 重導向到 HTTPS
    return 301 https://$server_name$request_uri;
}

server {
    listen 443 ssl http2;
    server_name your-domain.com;

    # SSL 憑證配置
    ssl_certificate /etc/nginx/ssl/your-domain.crt;
    ssl_certificate_key /etc/nginx/ssl/your-domain.key;
    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_ciphers HIGH:!aNULL:!MD5;

    # 安全標頭
    add_header X-Frame-Options DENY;
    add_header X-Content-Type-Options nosniff;
    add_header X-XSS-Protection "1; mode=block";

    # API 代理
    location /api/ {
        proxy_pass http://localhost:8000/api/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        
        # WebSocket 支援
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        
        # 超時設定
        proxy_connect_timeout 60s;
        proxy_send_timeout 60s;
        proxy_read_timeout 60s;
    }

    # Web 介面代理
    location / {
        proxy_pass http://localhost:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    # 檔案上傳大小限制
    client_max_body_size 50M;

    # 日誌配置
    access_log /var/log/nginx/linerag_access.log;
    error_log /var/log/nginx/linerag_error.log;
}
```

### 啟用配置
```bash
# 建立符號連結
sudo ln -s /etc/nginx/sites-available/linerag /etc/nginx/sites-enabled/

# 測試配置
sudo nginx -t

# 重新載入 Nginx
sudo systemctl reload nginx
```

## 🔒 SSL 憑證配置

### 使用 Let's Encrypt (免費)
```bash
# 安裝 Certbot
sudo apt install certbot python3-certbot-nginx

# 取得憑證
sudo certbot --nginx -d your-domain.com

# 自動更新憑證
sudo crontab -e
# 加入以下行：
0 12 * * * /usr/bin/certbot renew --quiet
```

### 使用自簽憑證 (測試用)
```bash
# 建立憑證目錄
sudo mkdir -p /etc/nginx/ssl

# 生成自簽憑證
sudo openssl req -x509 -nodes -days 365 -newkey rsa:2048 \
    -keyout /etc/nginx/ssl/linerag.key \
    -out /etc/nginx/ssl/linerag.crt \
    -subj "/C=TW/ST=Taiwan/L=Taipei/O=LineRAG/CN=localhost"
```

## 🔥 防火牆配置

### UFW (Ubuntu)
```bash
# 啟用防火牆
sudo ufw enable

# 允許必要端口
sudo ufw allow ssh
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp

# 限制資料庫存取 (僅本機)
sudo ufw deny 5432
sudo ufw deny 6333
```

### Firewalld (CentOS/RHEL)
```bash
# 啟用防火牆
sudo systemctl enable firewalld
sudo systemctl start firewalld

# 允許 HTTP/HTTPS
sudo firewall-cmd --permanent --add-service=http
sudo firewall-cmd --permanent --add-service=https
sudo firewall-cmd --reload
```

sudo tee /etc/logrotate.d/linerag > /dev/null <<EOF

    daily
    missingok
    rotate 30
    compress
    delaycompress
    notifempty
