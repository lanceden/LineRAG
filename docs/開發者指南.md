## 🎯 系統架構概述

LineRAG 是基於最新 AI 技術的企業級多租戶智能客服系統，採用先進的多模態 RAG 架構。

### 🔧 核心技術棧

**後端技術:**

- **API 框架**: FastAPI + SQLAlchemy + Pydantic
- **主資料庫**: PostgreSQL 15+ (用戶、公司、文檔元資料)
- **向量檢索**: 高效能向量資料庫 (語義搜尋)
- **知識圖譜**: 智能圖資料庫 (實體關係)
- **快取系統**: Redis (效能優化)

**AI 處理引擎:**
- **多模態 RAG**: 企業級檢索增強生成系統
- **文檔解析**: 高精度多模態解析引擎 (PDF、Office、圖像)
- **語言模型**: GPT-4o 系列深度整合
- **向量嵌入**: OpenAI text-embedding-3-large

**前端技術:**
- **框架**: Next.js 13+ App Router + TypeScript
- **樣式**: Tailwind CSS + shadcn/ui
- **狀態管理**: React Hooks + SWR
- **圖表**: Chart.js + D3.js (知識圖譜視覺化)

**部署和維運:**
- **容器化**: Docker + Docker Compose
- **反向代理**: Nginx (生產環境)
- **監控**: 內建 API 使用統計和健康檢查

```python
class NewFeatureBase(BaseModel):

    description: Optional[str] = None

    pass
```

#### 3. 建立 API 路由
```python
# app/routers/new_feature.py
from fastapi import APIRouter, Depends, HTTPException
from sqlalchemy.orm import Session
from typing import List

from app.core.database import get_db
from app.models.new_feature import NewFeature
from app.schemas.new_feature import NewFeatureCreate, NewFeatureResponse

router = APIRouter(prefix="/new-features", tags=["new-features"])

@router.post("/", response_model=NewFeatureResponse)
async def create_new_feature(
    feature: NewFeatureCreate,
    db: Session = Depends(get_db)
):
    db_feature = NewFeature(**feature.dict())
    db.add(db_feature)
    db.commit()
    db.refresh(db_feature)
    return db_feature

@router.get("/", response_model=List[NewFeatureResponse])
async def list_new_features(
    skip: int = 0,
    limit: int = 100,
    db: Session = Depends(get_db)
):
    features = db.query(NewFeature).offset(skip).limit(limit).all()
    return features
```

```typescript
// src/lib/api-client.ts
import axios from 'axios'

const apiClient = axios.create({
  baseURL: process.env.NEXT_PUBLIC_API_URL || 'http://localhost:8000/api',
  timeout: 10000,
})

// 請求攔截器
apiClient.interceptors.request.use(
  (config) => {
    const token = localStorage.getItem('access_token')
    if (token) {
      config.headers.Authorization = `Bearer ${token}`
    }
    return config
  },
  (error) => Promise.reject(error)
)

// 回應攔截器
apiClient.interceptors.response.use(
  (response) => response,
  (error) => {
    if (error.response?.status === 401) {
      localStorage.removeItem('access_token')
      window.location.href = '/login'
    }
    return Promise.reject(error)
  }
)

export default apiClient
```

```python
from sqlalchemy.orm import joinedload

companies = db.query(Company)\

    code = Column(String(50), unique=True, nullable=False, index=True)
    created_at = Column(DateTime, default=datetime.utcnow, index=True)
```

#### API 回應快取
```python
from functools import lru_cache
import redis

redis_client = redis.Redis(host='localhost', port=6379, db=0)

@lru_cache(maxsize=128)
def get_company_config(company_id: int):
    # 快取公司配置
    cache_key = f"company_config:{company_id}"
    cached = redis_client.get(cache_key)
    
    if cached:
        return json.loads(cached)
    
    # 從資料庫查詢
    config = db.query(Company).filter(Company.id == company_id).first()
    
    # 快取結果
    redis_client.setex(cache_key, 300, json.dumps(config))
    return config
```

## 🚀 部署和 CI/CD

### GitHub Actions 配置

#### 後端 CI/CD
```yaml
# .github/workflows/api-ci.yml
name: API CI/CD

on:
  push:
    branches: [main, develop]
    paths: ['apps/api/**']
  pull_request:
    branches: [main]
    paths: ['apps/api/**']

jobs:
  test:
    runs-on: ubuntu-latest
    
    services:
      postgres:
        image: postgres:15
        env:
          POSTGRES_PASSWORD: postgres
        options: >-
          --health-cmd pg_isready
          --health-interval 10s
          --health-timeout 5s
          --health-retries 5

    steps:
    - uses: actions/checkout@v3
    
    - name: Set up Python
      uses: actions/setup-python@v4
      with:
        python-version: '3.11'
    
    - name: Install dependencies
      run: |
        cd apps/api
        pip install -r requirements.txt
        pip install pytest pytest-cov
    
    - name: Run tests
      run: |
        cd apps/api
        pytest --cov=app tests/
    
    - name: Build Docker image
      run: |
        cd apps/api
        docker build -t linerag-api:${{ github.sha }} .
```
